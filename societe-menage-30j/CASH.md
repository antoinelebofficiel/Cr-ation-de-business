# Cash — réinvestir tout

## Float J1 (obligatoire)

Avant le 1er euro client :

| Poste | Ordre de grandeur |
|---|---|
| Micro / SIRET | 0–50 € |
| RC pro | 25–40 €/mois |
| Ads 7 jours | **350–500 €** |
| 1er job presta (tu avances) | 50–80 € |
| **Float mini** | **~500–700 €** hors les 1 500 € survie |

Pas de float ads = pas de société. Emprunter pour les ads **si** ça mange les 1 500 € = interdit (loi 6).

## Cycle (le vrai problème)

Les contrats B2B se paient **fin de mois**. Les ads et le presta se paient **maintenant**.

Donc J1–J14, le cash qui nourrit la machine vient des **one-shots** :

- Passage test commerce **95–160 €** encaissé avant ou le jour J  
- Particulier **vitres / ménage ponctuel** **≥ 149 €**, payé avant ou sur place  
- **100 % de cette marge** (après presta) → ads B2B + float 48 h presta

Les particuliers ne sont pas le métier. C’est le **carburant**. Dès que 5 contrats B2B sont en place, tu réduis le B2C au remplissage des après-midi vides.

## Compte d’exploitation cible J30 (run-rate)

Hypothèse tendue, pas un slogan :

| | |
|---|---|
| Contrats B2B actifs | **10–12** @ ~220 € |
| Run-rate mensuel | **2 200–2 600 €** |
| One-shots du mois | **1 000–2 000 €** |
| CA mois 1 | **3–5 k€** (stretch 6–8 k si samedis + ads tiennent) |
| Presta ≤ 45 % | |
| Ads = tout le reste après 1 500 € survie | |

Fin J30 tu n’as pas 20 k€. Tu as **un roster + une enchère + 2 prestas**. C’est la société.

## Tableau quotidien (3 colonnes)

```
encaissé_jour | payé_presta | ads_jour | caisse
```

Si `caisse` < (presta dû 48 h + 1 500 restant à provisionner) → ads = 0 demain.
