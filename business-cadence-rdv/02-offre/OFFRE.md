# Offre CADENCE

## Promesse
> Je remplis votre agenda de RDV B2B qualifiés. Vous closez.

## Pour qui (ICP)
Boîtes qui vendent **≥1 500 €** le ticket (ou ≥500 €/mois récurrent) :
- Agences / studios / freelances senior  
- Formations / coaching B2B  
- Artisans / installateurs high-ticket  
- SaaS / prestataires B2B locaux ou remote  

Anti-ICP : e-com low-ticket, “je sais pas qui est mon client”, pas de calendrier / pas d’offre claire.

## Ce qui est inclus (pilote)
1. Cadage offre + ICP (30–45 min)  
2. Script d’appel  
3. 1 liste / sourcing de base  
4. Appels (soir + WE)  
5. RDV posés + brief écrit par lead  

## Ce qui n’est pas inclus
- Closing final du client  
- Pub Meta gérée pour eux (sauf upsell séparé)  
- CRM custom  

## Garantie pilote (simple)
Si **0 RDV tenu** en 14j malgré offre claire + calendrier dispo : **1 semaine d’appels offertes** (pas de remboursement cash — protège la marge).  
Conditions : ICP figé, Calendly ouvert, réponse leads &lt;4h.
