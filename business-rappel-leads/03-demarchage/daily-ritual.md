# Rituel quotidien de démarchage

| Horaire | Bloc |
|---|---|
| 08:30–09:00 | Ad Library + Maps → 40 fiches / enrichissement |
| 09:00–12:00 | Appels (téléphone en main, Sheet ouverte) |
| 12:00–12:30 | Démos / follow-ups |
| 14:00–17:00 | Appels |
| 17:00–18:00 | Setups clients + 1 correction de pitch |
| Samedi AM | 30 appels si <3 closes dans la semaine |

## Quotas
- 60 appels/jour (ou 40 neufs + 20 relances)
- 10 SMS/LinkedIn/email de suivi
- 2–4 démos
- Close le jour même dès démo OK

## Fin de journée (10 min)
1. Remplir [daily-tracker](../04-phase0/daily-tracker.csv)
2. Noter objection #1 du jour
3. Corriger **une** ligne du script
4. Préparer les 20 premiers appels de demain
