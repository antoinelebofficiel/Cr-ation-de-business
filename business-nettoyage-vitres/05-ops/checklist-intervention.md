# Checklist intervention

## Avant (toi → prestataire)
- [ ] Adresse + digicode / contact sur place
- [ ] Offre : intérieur / extérieur / fréquence
- [ ] Photos préalable si dispo
- [ ] Accès eau / électricité
- [ ] Contraintes horaires (avant 9h, pendant fermeture…)

## Sur place (prestataire)
- [ ] Se présenter + confirmer zones
- [ ] Protéger sols / caisse enregistreuse / stock vitrine
- [ ] Nettoyage cadre + verre + coins
- [ ] Essuyage sans traces (lumière rasante = contrôle)
- [ ] Remise en place éventuelle
- [ ] Photos avant/après (3–6)

## Après
- [ ] WhatsApp photos + “terminé”
- [ ] Client confirme OK (SMS / oral)
- [ ] Toi : encaissement / facture / prochain créneau
- [ ] Si KO : repasage 48h

## Matériel minimum prestataire
Raclette pro · mouilleur · microfibres · produit vitres · perche si besoin · échelle stable <3,5 m · seau · signalétique sol si passage public
