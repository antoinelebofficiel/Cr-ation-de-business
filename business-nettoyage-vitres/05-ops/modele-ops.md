# Modèle ops — tu ne nettoies pas

## Rôle
| Qui | Fait |
|---|---|
| **Toi** | Vente, ads, close, planning, encaissement, réclamations graves |
| **Prestataire** | Intervention, photos, compte-rendu WhatsApp |
| **Pas toi** | Seaux, perches, samedis sur vitrine “parce que y a personne” |

## Flux
1. Close client → date posée
2. Brief prestataire (adresse, accès, offre, photos)
3. Intervention
4. Photos + “OK client”
5. Paiement / facture
6. Si contrat : prochain créneau auto dans le sheet

## Capacité
- 1 prestataire actif ≈ **4–6 interventions/jour** max réaliste
- Phase 0 : **1 prestataire suffit** jusqu’à ~8–10k CA
- Recruter le 2e **avant** saturation (file d’attente >5 jours)

## Si prestataire lâche le jour J
1. Proposer report client <48h
2. Activer backup prestataire
3. **Interdit** : y aller toi-même (sauf urgence réputation **et** <1×/mois — noter la dette)

## Outils Phase 0
- Google Sheet planning
- WhatsApp Business
- SumUp / Stripe / virement
- Drive photos avant-après

Pas de logiciel “field service” avant 15k CA.
