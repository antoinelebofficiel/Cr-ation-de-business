# 3 entrepreneurs — comment ils écraseraient Lorient (vitres)

Contexte : LUCIDE, Lorient, tu vends le **passage**, pas le RDV.  
Objectif : aller **beaucoup** plus vite que les laveurs locaux + que toi en mode “automation d’abord”.

---

## 1. Alex Hormozi — l’offre + le volume d’attempts

**Ce qu’il ferait**
- Une offre tellement simple que le “non” devient bizarre.
- Mesurer les **attempts** (appels, SMS, closes), pas les idées.

**Version LUCIDE**
> “1er passage sous 7 jours. Si traces après intervention → repasage 48h offert. 89 €/mois ou passage test. Mardi 7h30 ou jeudi 7h30 ?”

**Règles qu’il imposerait**
| Métrique | Quota |
|---|---|
| Attempts / jour | 40–60 (appel ou SMS perso avec hook) |
| Offre | Figée 14 jours — pas de rebuild |
| Automation email+vitrine | **Interdite** tant que <10 closes manuels |

**Phrase Hormozi pour toi**  
Le goulot n’est pas la tech. C’est le nombre de fois où tu proposes un **passage daté**.

## 2. Elon Musk — supprimer des étapes (algo)

**Ce qu’il ferait**
1. Questionner chaque étape  
2. **Supprimer**  
3. Simplifier  
4. Accélérer  
5. Automatiser **en dernier**

**Ce qu’il supprimerait chez toi**
| Étape | Verdict |
|---|---|
| RDV 15 min | DELETE — tu vends le passage |
| Devis PDF | DELETE — prix oral + SMS |
| Email de masse / usine Street View J1 | DELETE (trop d’étapes avant cash) |
| Toi sur le balai | DELETE |
| 3 villes | DELETE |
| “Présenter LUCIDE” | DELETE — hook + créneau |

**Process Musk (minimal)**
```
Hook (1 fait visible)
  → “interne ou presta ?”
  → prix en 1 phrase
  → mardi / jeudi
  → SMS OUI
  → presta
  → encaisser
```

**Phrase Musk pour toi**  
Si tu automatises avant d’avoir close à la main, tu accélères la **mauvaise** machine.

## 3. John D. Rockefeller — monopoliser une poche, pas “le marché”

**Ce qu’il ferait**
- Pas “toute la Bretagne”.
- Contrôler **une rue / un quartier**, puis le suivant.
- Densité = barrière : quand 8 vitrines d’une artère sont à toi, le concurrent local est mort sur cette poche.

**Version Lorient (ordre d’attaque)**
1. **Une seule artère** centre-ville (ex. axe commerçant principal) — 100 % des vitrines contactées en 7 jours  
2. Objectif poche : **≥5 passages/contrats** sur cette artère  
3. Preuve sociale visible (avant/après + bouche-à-oreille commerçants)  
4. Artère #2 (Lanester / autre) **seulement après**

**Ce qu’il refuserait**
- Scatter 200 SMS sur toute l’agglo sans profondeur  
- Automation France alors que tu n’as pas une rue  
- “Notoriété de marque” avant densité

**Phrase Rockefeller pour toi**  
La vitesse n’est pas géographique. C’est **saturation locale** plus vite que le prochain qui appelle une fois par mois.
