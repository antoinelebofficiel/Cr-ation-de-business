# PREUVE

Agence-média : on filme le quotidien des fondateurs, on livre 12 clips de 30–45s, une YouTube, et un épisode du média *Une journée avec*.

## Offre

| Offre | Prix | Contenu |
| --- | --- | --- |
| Pilote | 6 500 €/mois × 90j + 2 500 € setup | 3 premiers fondateurs, Saison 1 |
| Saison | 8 500 €/mois + setup | 1 jour, 12 clips, 1 YouTube |
| Empire | 14 500 €/mois + setup | 2 jours, 20 clips, 2 YouTube, 3 000 € d’ads |

Cible 90 jours : **161 000 €** à 8 clients max. Détail et scripts : `/systeme`.

## Stack

Vite + React, formulaires Netlify, hébergement Netlify.

```bash
npm install
npm run dev
```

## Règle d’exploitation

Antoine vend. Des freelances filment et montent. Stop vente si un clip a plus de 5 jours de retard.
