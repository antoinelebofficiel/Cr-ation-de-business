# PREUVE

Agence-média : on filme le quotidien des fondateurs, on livre 12 clips de 30–45s, une YouTube, et un épisode du média *Une journée avec*.

## Offre

| Offre | Prix | Contenu |
| --- | --- | --- |
| Moteur | 3 900 €/mois + 1 500 € setup | 24 clips, 8 LinkedIn, 1 YouTube |
| Moteur + Ads | 6 400 €/mois | Moteur + 2 500 € d’ads |

Cible 90 jours : **134 100 €** à 14 clients. Acquisition industrialisée : `/acquisition`.

## Stack

Vite + React, formulaires Netlify, hébergement Netlify.

```bash
npm install
npm run dev
```

## Règle d’exploitation

Antoine vend. Des freelances filment et montent. Stop vente si un clip a plus de 5 jours de retard.
